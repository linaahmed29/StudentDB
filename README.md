
# Student Database

A simple app to keep track of students. You can add, change, delete, and search students. Made with C++, Qt, and SQLite.

## What it can do

- Add a new student
- Edit a student (click a row in the table first)
- Delete a student
- Search by first name, last name, ID, major, or address
- Search by birthdate: before, on, or after a date, or by year or month
- Show all students again

## What it saves

ID, first name, last name, SSN, major, birthdate, address, and GPA.

## How to run it

1. Install Qt 6 and Qt Creator.
2. Download this project.
3. In Qt Creator, open `CMakeLists.txt`.
4. Click **Configure Project**, then press **Ctrl+R**.
